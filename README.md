# homebrew-tap

Homebrew formulae for [arhuman](https://github.com/arhuman)'s tools.

## Usage

```bash
brew tap arhuman/tap
brew install ansible-static-lint
```

## Formulae

| Formula | Description |
|---------|-------------|
| `ansible-static-lint` | Fast static linter for Ansible playbooks and roles (`astl`), no Python required |
